# Finance & Expense Dashboard Project

## Overview
This project simulates a corporate finance dashboard to track budget vs actual spending across departments and cost centers. The goal is to identify overspend, savings, and approval status risks.

## Dataset
- **Expense_ID**: Unique expense record
- **Date**: Expense date
- **Department**: Finance, IT, HR, Operations, Marketing
- **Cost_Center**: Department-specific code
- **Expense_Category**: Type of expense (Salaries, Travel, Software, etc.)
- **Budgeted_Amount**: Planned expense
- **Actual_Amount**: Actual expense
- **Variance**: Actual minus Budget
- **Approval_Status**: Approved, Pending, Rejected

## KPIs & Analysis
- Total Budget vs Actual by Department
- Department-wise Variance
- Approval Status Summary
- High-Risk Cost Centers

## Tools & Features
- Microsoft Excel
- Pivot Tables
- Charts (Column, Bar, Pie)
- Slicers for interactivity
- Conditional Formatting

## Insights
- IT department overspent by ₹12,000 — top risk cost center: IT-CC02
- 70% of expenses approved, 20% pending, 10% rejected
- Operations department is under budget — savings realized
